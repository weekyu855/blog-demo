## 三、安装步骤

### 第一步：开启CPU虚拟化

这一步是虚拟机正常运行的关键，很多朋友安装失败都是因为没开虚拟化：

1. 重启电脑，在开机时按下BIOS快捷键（通常是F2、F10、Del，不同品牌不一样，开机界面会有提示）
2. 在BIOS中找到"Intel VT-x"或"AMD-V"选项，将其设置为"Enabled"
3. 保存设置并退出，电脑会自动重启

### 第二步：安装VMware Workstation Player

1. 运行下载好的安装程序，一路点击"下一步"
2. 完成安装后重启电脑

### 第三步：创建Windows 11虚拟机

1. 打开VMware，点击"创建新虚拟机"
2. 选择"安装程序光盘映像文件"，浏览找到你下载好的Windows 11 ISO文件
3. 选择客户机操作系统：Microsoft Windows → 版本选择Windows 11 x64 → 点击下一步
4. 设置虚拟机名称和存储位置（建议剩余空间至少留60GB以上）
5. 设置磁盘大小，推荐至少分配60GB，选择"将虚拟磁盘存储为单个文件"
6. 点击"完成"，虚拟机创建完毕

### 第四步：配置虚拟机满足Win11要求

Win11要求TPM 2.0和安全启动，我们需要简单配置一下：

1. 右键点击创建好的虚拟机，选择"设置"
2. 切换到"选项" → "高级"，确认固件类型为UEFI，勾选"启用安全启动"
3. 如果提示TPM问题，在设置中添加"可信平台模块"设备即可
4. 根据你的电脑配置分配处理器核心和内存，推荐至少分配2核4G内存，这样运行起来比较流畅

## 四、常见问题解决

### 1. 提示不满足Win11安装要求

如果你的硬件不支持TPM，可以在安装进入第一次重启后，当提示不满足要求时，按Shift+F10打开CMD，输入：

```
regedit
```

打开注册表，定位到：

```
HKEY_LOCAL_MACHINE\SYSTEM\Setup\MoSetup
```

右键右侧空白处 → 新建 → DWORD(32位)值，命名为 `AllowUpgradesWithUnsupportedTPMOrCPU`，双击将值设为 `1`，关闭注册表，重启安装程序即可绕过检查。

### 2. Hyper-V导致虚拟机运行卡顿

很多朋友电脑开启了Hyper-V，会和VMware冲突导致卡顿，我们可以关闭它：

1. 以管理员身份打开CMD，执行：

```
bcdedit /set hypervisorlaunchtype off
```

2. 重启电脑，就关闭Hyper-V了，VMware性能会提升很多

### 3. 内存完整性导致无法开启虚拟机

Windows安全中心的内存完整性也可能导致冲突，解决方法：

1. 打开Windows安全中心 → 设备安全性 → 核心隔离详情
2. 关闭"内存完整性"，重启电脑即可
